Valbli — Latin-to-Block Converter

An interactive tool that converts Lojban text written in the Latin alphabet into the Valbli block writing system. Consonant letterforms are extracted from the original font source Sefta.sfdir; vowel letterforms are drawn using the new unified featural design (three families: chevron / stem / circle). Syllables are split automatically per the official CLL §3.9 rule, and blocks are built using the recursive split rule. The rendered output below is drawn as pale ink on a black ground, packed tightly into each square with no internal divider lines, closer to the density of a CJK character.

Converter

Type Lojban words in lowercase Latin letters, separated by spaces. Use a standalone "." (preceded by a space) to mark the end of an utterance (the filled square). Each word is automatically separated from the next by a small word-boundary dot. The horizontal left-to-right layout here is a practical demo choice only — the official writing direction is still undecided (see the Backlog section in README.md).

Built on top of the original valbli-master project, extended with this design session's decisions (vowels, block template, syllabification, lujvo, punctuation, and handwriting guidance).
